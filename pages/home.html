// CAPABILITIES

Built for privacy.
Engineered for performance.

Every feature in SentryEye is designed around a single constraint: your data stays on your device, always.

📸
intruder_detection
Intruder Detection

Silently captures a front-camera image on repeated PIN failures. Images are encrypted and stored locally in the secure Room database — never transmitted.

🔒
local_sandbox
Local Sandbox Architecture

All threat data, captures, and logs are stored in an AES-256 encrypted SQLite/Room database on-device. Zero external servers means zero attack surface.

☁️
cloud_sync
Direct Cloud Sync

Optional Google Drive backup uses direct OAuth 2.0 authentication. Your encrypted backup travels directly device-to-Drive with no intermediate storage or logging.

⚡
compose_ui
Jetpack Compose UI

Built natively with Jetpack Compose for a lightweight, fluid interface. Background processing is meticulously optimized to maintain <2% battery overhead.
