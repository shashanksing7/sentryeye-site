// ABOUT

The tools we build
don't know who you are.

SentryEye was born from a frustration: every mobile security app on the market was harvesting more data than the threats it claimed to protect against. We believed that security software had no business knowing anything about you.

So we built our own. A single-developer utility, open-sourced from day one, with a strict covenant: all operations run locally, always. The architecture was never an afterthought — it was the founding constraint.

// PHILOSOPHY

Three principles.
No exceptions.

01 / LOCAL_FIRST
Local-First by Design

Every feature is architected around local execution. Network access is a privilege granted explicitly by the user, not a default behavior.

02 / OPEN_SOURCE
Radical Transparency

The source code is public and auditable by anyone. Trust should be verifiable, not a marketing claim. Read it, fork it, scrutinize it.

03 / MINIMAL_SURFACE
Minimal Attack Surface

We request only the permissions we need, use only the APIs we must, and ship the smallest binary that does the job correctly.
